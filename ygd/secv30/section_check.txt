   ▷ 사용성 검토(균열검토)

      Ms = 450.000kN.m  (사용하중조합-Ⅰ)
    - 균열발생 여부 검토 (비균열 단면으로 가정)
      n  = Es/Ec = 200,000 / (0.077 mc^1.5 * ³√(Fck + Δf)) =  7
      Xo = (B·H²/2 + (n-1)·As·D) / (B·H + (n-1)·As) = 615.560mm
      Io = B·H³/12 + B·H·(H/2-Xo)²+ (n-1)·As·(D-Xo)²= 61334449482.618mm⁴
      fct = Ms / Io×(H-Xo) = 4.288MPa >  fctk = 2.204MPa ∴ 균열 단면 검토

    - 철근응력제한 검토
      ρ = As/(B·D) =  0.00584
      k  = -nρ+ √((nρ)²+ 2nρ) = 0.248  (j= 1-k/3= 0.917)
      x  = k·d =  272.76101mm
      fc = 2·Ms / (B·x·(D - x/3)) =  8.17476MPa
      fs = Ms / (As ·(D - x/3))   =  173.54877MPa ≤  0.8fy = 320.000MPa ... ∴O.K
