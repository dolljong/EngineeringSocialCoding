2.필요철근량 검토

 Md = As x ΦS x fy x (d - β x c) ------------------------ ① 
 c = As x ΦS x fy / (α x ΦC x 0.85 x fck x b) ---------- ② 

 ①식과 ②식을 연립하여 필요 철근량을 구한다.

 As_req = 348.546㎟

  사용철근 1단 : H 22 x 8ea = 3096.8㎟
             2단 : H 0.0 x 0.0ea = 0㎟
             3단 : H 0.0 x 0.0ea = 0㎟,   As_total = 3096.8㎟

  사용전단철근 : H 22 x 2ea/m,   간격 : 400mm 


3.최소철근량 검토

 As_min1 = ( 0.25 x √(fck) / fy ) x b x d
           = ( 0.25 x √(30) / 400) x 1000 x 720 = 2464.752㎟
 As_min2 = ( 1.4 / fy ) x b x d
           = ( 1.4 / 400) x 1000 x 720 = 2520.0㎟
 As_min3 = 4/3 x As_req = 464.727㎟

 As_use > As_min = 3096.8㎟  >  464.727㎟  --> OK!

4.최대철근량 검토

         = 0.004 x 1000 x 720 = 28800.0㎟

5.중립축 깊이 검토

 C_max = (δ x εcu / 0.0033-0.6) x d
         = (1.0 x 0.0033 / 0.003 - 0.6) x 720 = 288.0 mm

 C = (As x Φs x fy)/(α x Φc x 0.85 x fck x b)
   = (3096.8 x 1.0 x 400) / (0.8 x 1.0 x 0.85 x 30 x 1000) = 60.722 mm

 최대중립축 깊이 > 중립축의 깊이 = 288.0mm  >  60.722mm --> OK!

6.인장철근 변형률 검토

 εs = (d-c)/c x εcu
    = (720 - 60.722) / 60.722 x 0.0033 = 0.036

 εyd = (Φs x fy)/Es
     = (1.0 x 400) / 200000 = 0.002

 εs = 0.036  >   εyd = 0.002 ----> OK!

 1. 균열제어를 위한 최소철근량 검토

   - kc = 균열발생 직전의 단면 내 응력분포 상태를 반영하는 계수 = 0.4
   - k = 간접하중영향에 의해 부등 분포하는 응력의 영향을 반영하는 계수 = 0.65
   - Act = 콘크리트의 유효 인장 단면적 = 200000.0 ㎟ 
   - fct = 첫 균열이 발생할 때 유효한 콘크리트 인장강도 = 3.149 MPa
   - fs = 첫 균열 발생 직후에 허용하는 철근의 인장강도( = Mo/(As*(d-(x/3))) = 48.101 MPa
   - As_min = 균열제어를 위한 최소철근량
   -        = kc x k x Act x fct/fs
   -        = 0.4 x 0.65 x 200000.0 x 3.149/48.101 = 3403.708 ㎟

   As_use = 3096.8 ㎟  <  As_min = 3403.708 ㎟  ------> NG!!!

 2. 간접균열제어 (철근콘크리트 기준)

   - 균열제어를 위해 철근의 발생응력에 따라 최대 철근지름과
     최대 철근간격기준을 준수한다.(도.설.기 5-125)
   - 최소철근량 조건을 만족하고,
     배치된 철근이 최대 철근지름과 최대 철근간격 중 하나를 만족한다면
     균열폭이 허용 한계값 이내에 있다고 간주할 수 있다.
     이 때 철근응력은 균열단면을 기준으로 계산하여야 한다.

    - fs = 철근응력 = Mo/(As*(d-(x/3)) = 48.101 MPa

   최대 철근지름(mm) = 32 mm   >   사용 철근지름(mm) = 22 mm  ------> OK!

   최대 철근간격(mm) = 300 mm   >   사용 철근간격(mm) = 114.0 mm  ------> OK!
