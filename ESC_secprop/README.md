# 단면 특성 계산기 (ESC_secprop)

브라우저(2D Canvas)에서 동작하는 구조 단면 특성 계산기. 면적 `A`, 도심 `Cx/Cy`, 단면2차모멘트 `Ixx/Iyy/Ixy` 를 계산하고, 탄성계수가 다른 두 재료의 합성 단면(환산단면)까지 지원합니다.

## 실행

별도 빌드/서버 불필요. `index.html` 을 브라우저에서 열면 됩니다.

```
ESC_secprop/index.html
```

## 기능 요약

- 입력 방식 두 가지: **폐곡선(좌표열)** / **조각(R·T)**
- 계산 방법 두 가지(폐곡선 모드): **Green 정리** / **사다리꼴 분할(도심축정리)**
- **다중 재료(환산단면)** 지원: 재료 수 1·2개 선택 + E1·E2 + 기준재료 지정
- 변수·수식·주석 지원 입력 문법 (변수 정의, `;` 주석)
- 줌·팬·뷰리셋, 도심 중립축 표시
- 사다리꼴 분할/조각 입력 시 조각별 상세표, 행 클릭으로 캔버스 강조
- mm/cm/m 단위 자유 환산 (입력단위 ↔ 출력단위)

## 입력 방식

### A. 폐곡선 (좌표열)

연속된 점을 시계/반시계 한쪽 방향으로 입력. 첫 점과 마지막 점 사이에 자동으로 닫힘 변이 추가됩니다.

```
H=2    ; 변수 정의 (수식 사용 가능, ; 이후는 주석)
B=1
t=0.2

p1, 0,        0           ; 좌하
p2, p1.x+B,   p1.y        ; 점 참조 .x / .y
p3, p2.x,     p2.y+H
p4, 0,        p3.y
```

- 라인 형식: `이름, x수식, y수식`
- 점 참조: 다른 점의 좌표를 `점이름.x` / `점이름.y` 로 참조
- **하나의 closed loop**로 표현해야 하므로 내부 hole이 있으면 **bridge edge**로 외곽과 내곽을 연결 (예제 `중공 직사각형` 참고)

### B. 조각 (직사각형 R · 직각삼각형 T)

```
B=300
H=500
t=20

flg_b, R, 0,         0,       B,  t           ; 직사각형
web,   R, (B-t)/2,   t,       t,  H-2*t       ; 변수·수식 그대로
flg_t, R, 0,         H-t,     B,  t

bs_L,  T, ob,        tb,      -ob, sb         ; 직각삼각형
```

- 라인 형식: `이름, R|T, x, y, b, h`
- **R(직사각형)**: 삽입점 `(x,y)` 가 한 코너. 꼭짓점 4개는 `(x,y)`, `(x+b,y)`, `(x+b,y+h)`, `(x,y+h)`. 면적 `|b·h|`
- **T(직각삼각형)**: 직각이 삽입점 `(x,y)`. 다른 두 꼭짓점 `(x+b,y)`, `(x,y+h)`. 면적 `|b·h|/2`
- `b`/`h` **부호**는 **방향만** 결정 (직각이 바운딩 박스의 LL/LR/UR/UL 중 어느 코너인지). 면적은 항상 양수
- 각 조각이 곧 재료 추가분 (조각 모드는 hole 직접 표현 불가)

## 계산 방법 (폐곡선 모드)

| 방법 | 설명 |
|---|---|
| **Green 정리** | 변을 따라 선적분 (shoelace 기반). 빠르고 결과만 보고 싶을 때. |
| **사다리꼴 분할** | 각 변에 대해 기준선(y=min)까지의 사다리꼴을 직사각형+삼각형으로 분해, 도심축정리로 합산. 분할 상세표 + 시각화 함께 제공. |

> 조각 모드는 입력 자체가 분해된 상태라 항상 "조각 합산" 방식. 결과 표 아래 상세표가 자동으로 표시됩니다.

---

## 다중 재료 (환산단면)

탄성계수가 다른 두 재료의 합성 단면을 환산단면법으로 계산.

1. 좌측 패널에서 **재료 수 = 2개** 선택
2. `재료1 E`, `재료2 E` 입력 후 **기준** 라디오로 기준재료 지정
3. 형상 입력 텍스트박스가 **재료1 형상** / **재료2 형상**으로 분리
4. 결과는 모두 **환산값** (기준재료 기준)

환산비: `n_i = E_i / E_ref`

- 환산면적: `A_t = Σ n_k · A_k`
- 환산도심: `C_t = Σ n_k · A_k · c_k / A_t`
- 환산 단면2차모멘트(도심축정리): `I_t = Σ n_k · (I'_local,k + A_k · d_k²)`

예: 강박스(E1=7) + 콘크리트슬래브(E2=1), 기준 = M2(콘크리트) → 강박스 면적이 7배 환산되어 합산.

### 폐곡선 모드 + 2재료: 도심축정리 과정 상세표

폐곡선 모드에서 재료를 2개로 설정하면, 결과 패널에 **`폐곡선별 단면특성 + 환산단면 도심축정리`** 표가 자동 출력됩니다. 각 행은 한 폐곡선의 전체 계산 단계를 보여줍니다:

| 컬럼군 | 내용 |
|---|---|
| 재료, E, n | 폐곡선 라벨, 입력 E, 환산비 n = E/E<sub>ref</sub> |
| 기하 단면특성 | A, C<sub>x,k</sub>, C<sub>y,k</sub>, I'<sub>xx,k</sub>, I'<sub>yy,k</sub> (쉘레이스 결과, 본래값) |
| n·A | 환산면적 |
| 편차 | d<sub>y</sub> = C<sub>y,k</sub> − C<sub>y,total</sub>, d<sub>x</sub> 동일 |
| 평행축 | n·A·d<sub>y</sub>², n·A·d<sub>x</sub>² |
| 합산 기여 | I<sub>xx,k</sub> = n·I'<sub>xx,k</sub> + n·A·d<sub>y</sub>², I<sub>yy,k</sub> 동일 |

Σ 행에는 환산 합계(전체 환산도심·면적·I<sub>xx</sub>·I<sub>yy</sub>)가 표시됩니다. 폐곡선 행을 클릭하면 캔버스에서 해당 폐곡선의 외곽선이 주황색으로 강조됩니다.

---

## 단위

좌측 패널 **입력 단위 / 출력 단위** 드롭다운으로 mm / cm / m 간 자유 변환. 입력값은 입력단위로 해석, 결과표는 출력단위로 환산하여 표시. 단위 변경은 즉시 표시에 반영(재계산 불필요).

| 동작 | 결과 |
|---|---|
| 마우스 휠 | 휠 위치 기준 줌 인/아웃 |
| 드래그 | 패닝 |
| 우상단 `뷰 리셋` | 줌·팬 초기화 |

- 단일재료: 초록색 외곽선/채움
- 다중재료: M1=초록, M2=파랑
- 도심 중립축: x축=파랑 점선, y축=빨강 점선

## 입력 문법 레퍼런스

```
;  ← 주석 (이후 무시)
=  ← 변수 정의: H=2  또는  H=2, B=1, t=0.2
```

### 수식
- 사칙연산: `+ - * /`, 괄호 `()`
- 다른 변수 참조: `B/2`, `(H-2*t)`
- 폐곡선 모드에서 다른 점 참조: `p1.x + B`, `p2.y - t`
- 안전한 부분식 평가 (`Function` 기반)

### 데이터 라인
- 폐곡선: `이름, x수식, y수식` (필요시 3개 이상 콤마 시 마지막이 y, 앞이 x 수식 — 콤마 포함 수식 허용)
- 조각: `이름, R|T, x수식, y수식, b수식, h수식`

## 수학적 배경 (간략)

- **단일재료 / 폐곡선 모드 Green 정리**: shoelace 적분으로 `A`, `Cx`, `Cy`, `Ixx_origin`, `Iyy_origin`, `Ixy_origin` 계산 후 도심축으로 평행축 환산
- **사다리꼴 분할**: 각 변에 대해 기준선까지의 trapezoid 영역을 `직사각형(가로) + 직각삼각형(기울어진 윗부분)` 으로 분해. 직각삼각형은 기울어진 변에만 생성
- **조각 모드**: 사용자가 직접 분해한 R·T 조각을 합산. 면적 항상 양수
- **다중 재료(환산단면)**: 각 조각/폐곡선의 환산비 `n_k = E_k / E_ref` 를 면적과 단면2차모멘트에 곱해 도심축정리로 합산. 결과는 기준재료에서의 환산값 (휨해석 시 `EI = E_ref · I_t`)

## 변경 이력 (요약)

- 사다리꼴 분할 + 도심축정리 옵션 추가, 조각 모드 추가
- 조각 행 클릭 강조, 조각 라벨/테두리 시각화
- 결과 영역 고정 높이(그림영역 유지), 표에 폭/높이 컬럼 추가
- PSC거더 예제 추가/개선
- 다중재료(환산단면) 지원, 강박스+슬래브 합성 예제 추가, 결과를 A/C/I로 단순화
- PSC거더+슬래브 합성 예제 추가 (pieces / polygon 모드)
- 강박스+슬래브 합성 폐곡선 모드 버전 추가
- 폐곡선 모드 + 2재료: 폐곡선별 단면특성과 도심축정리 합산 과정 상세표 출력
- 폐곡선 행 클릭으로 해당 폐곡선 캔버스 강조
