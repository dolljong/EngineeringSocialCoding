2) 콘크리트 재료상수
============================================================
  n (상승곡선부 형상지수)      = 2.0000
  εco,r (최대응력 변형률)      = 0.00200
  εcu,r (극한변형률)           = 0.00330
  αcc (유효계수)               = 0.85
  fcd (설계압축강도)           = 19.34 MPa
  fcm (평균압축강도)           = 39.00 MPa
  Ec (탄성계수)                = 32640.41 MPa
  α (압축합력 응력계수)        = 90.0000
  β (압축합력 위치계수)        = 0.4000
  η (등가응력블록 크기계수)    = 1.0000
  β1 (등가응력블록 깊이계수)   = 0.8000

============================================================
3) 철근 재료상수
============================================================
  fyd (설계인장강도)           = 280.00 MPa
  εyd (설계항복변형률)         = 0.001400

============================================================
4) 필요철근량 산정
============================================================
  Mu = As × fyd × (d - a/2)  -------- ①
   a = As × fyd / (η × fcd × b)  ---- ②
  식②를 식①에 대입하여 이차방정식으로 As를 구한다

  Asreq = 498.5 mm²

============================================================
5) 사용철근량
============================================================
  Asuse = 4053.6 mm², 철근도심: dc = 80.0 mm
  사용율 = 8.131
  1단: H25 - 8 EA (= 4053.6 mm², dc1 = 80.0 mm)
  2단: H0 - 0 EA (= 0.0 mm², dc2 = 0.0 mm)
  3단: H0 - 0 EA (= 0.0 mm², dc3 = 0.0 mm)

============================================================
6) 철근량 검토
============================================================
  As,min = (0.25√fck / fy) × b × d = 2662.2 mm²
         = (1.4 / fy) × b × d = 2520.0 mm²
         = As_req × 4/3 = 664.7 mm²
  As,use = 4053.6 mm² ≥ As,min = 664.7 mm²  ∴ O.K
  As,max = 0.04 × b × d = 28800.0 mm² ≥ As,use  ∴ O.K

============================================================
7) 중립축 깊이 검토
============================================================
  Cmax = (δ × εcu / 0.0033 - 0.6) × d
       = (1.0 × 0.00330 / 0.0033 - 0.6) × 720.0 = 288.0 mm
  C = Φs × As × fy / (α × Φc × 0.85 × fck × b)
    = 0.70 × 4053.6 × 400.0 / (90.00 × 0.65 × 0.85 × 35.0 × 1000.0)
    = 73.4 mm < Cmax = 288.0 mm  ∴ O.K

============================================================
8) 인장철근 변형률
============================================================
  εs = (d - C) / C × εcu
     = (720.0 - 73.4) / 73.4 × 0.00330 = 0.02908
  εyd = Φs × fy / Es
      = 0.70 × 400.0 / 200000 = 0.00140 ≤ εs  ∴ 항복가정 O.K

============================================================
9) 설계 휨강도 산정
============================================================
  Mr = As × Φs × fy × (d - β × c)
     = 4053.6 × 0.70 × 400.0 × (720.0 - 0.40 × 73.4)
     = 783,896,305.3 N.mm ≥ Mu = 100,000,000.0 N.mm  ∴ O.K
  [S.F = 7.839]
============================================================
10) 전단검토
============================================================
  Vcd = [0.85 × Φc × k × (ρ × fck)^(1/3) + 0.15 × fn] × b × d
      = [0.85 × 0.65 × 0.650 × (0.005630 × 35.0)^(1/3) + 0.15 × 0.006] × 1000.0 × 720.0
      = 354,164 N

  k = 1 + √(200/d) = 1 + √(200/720.0) = 0.650 (≤ 2.000)
  ρ = As / (b × d) = 4053.6 / (1000.0 × 720.0) = 0.005630 ≤ 0.0200
  fn = Nu / Ac = 0.006 MPa (≤ 0.2Φc×fck = 4.550 MPa)

  Vcd,min = (0.4 × Φc × fctk + 0.15 × fn) × b × d
         = (0.4 × 0.65 × 2.415 + 0.15 × 0.006) × 1000.0 × 720.0
         = 452,775 N

  Vcd = 452,775 N ≥ Vu = 50,000 N  ∴ 전단보강 불필요

============================================================
11) 최소 전단철근량 검토
============================================================
  Av,use = 397.2 mm² (H16 - 2ea, C.T.C = 400.0 mm)
  ρv,min = (0.08 × √fck) / fvy = (0.08 × √35.0) / 400.0 = 0.001183
  ρv,use = 397.2 / (400.0 × 1000.0 × sin90.0) = 0.001111 < 0.001183  ∴ N.G

============================================================
12) 전단철근 간격검토
============================================================
  종방향 Smax = 0.75 × 720.0 × (1 + cot90.0) = 540.0 ≥ 400.0  ∴ O.K
  횡방향 Smax = min(0.75 × 720.0, 600.0) = 540.0 ≥ 500.0  ∴ O.K
============================================================
14) 균열검토
============================================================

① 비균열 가정시 인장 연단 응력(사용하중조합-I)
